# 法規時效性查證

## 使用情境

知識庫裡的內容是「快照」，不是法規本身。法規會修正、廠商型錄會改版、採購門檻金額會重新公告。當你（或 AI）準備引用任何規範性數值——尺寸、比例、面積上限、金額門檻、罰則、廠商規格——之前，使用本知識判斷「需不需要先查最新版」。

## 學習目標

- 目標一：內化鐵則——任何規範性數值輸出時必附「法源條號＋查證日期」，做不到就標示「未查證」並如實說明
- 目標二：熟記強制重新查證的七個觸發條件（資料逾一年、涉及金額、廠商規格、版次型標準、來源標示未查證、送審／簽約用途、涉及特定縣市）
- 目標三：熟悉查證管道的優先順序：MCP 工具 → 全國法規資料庫（要看修正沿革，不是只看條文）→ 主管機關官網 → 向使用者索取現行文件

## 實務應用

- **送審前**：所有引用數值重新過一輪最新條文，尤其是建築技術規則——它歷來一年修正多次。
- **版次型標準**（綠建築評估手冊、建築能效、耐震規範）：先確認「哪一版」，再談數值。不指明版次的引用一律視為不完整。
- **廠商資料**（電梯機道尺寸等）：知識庫的表是某年快照，機型會停產、規格會改；正式設計以廠商現行型錄與核准函為準。
- **回答時附上 Data Currency 區塊**：來源、查證日期、變動風險等級，讓下一個讀的人知道這筆資料多新鮮。

## 常見陷阱

- 「知識庫裡有寫」不等於「有來源」——來源是條文本身，知識庫只是轉載。
- 只看條文不看「沿革」頁籤，引到已被修正的舊文字。
- MCP 工具不可用時默默跳過查證、照樣用確定語氣回答——正確做法是明講「本次未能查證」並降級確定性標示。

## 參考法規

- 全國法規資料庫（law.moj.gov.tw）：條文現行版與修正沿革
- 內政部國土管理署（前營建署）：建築法規函釋與公告
- 行政院公共工程委員會：採購金額門檻（公告金額、查核金額、巨額）公告
- 各縣市建管處：地方審查基準與自治法規
