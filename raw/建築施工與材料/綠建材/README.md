# 綠建材 (Green Building Materials)

依據財團法人臺灣建築中心（TABC）綠建材標章公開資料整理之技能知識庫。

## 綠建材檢索與選用平台（GM Web）

[綠建材檢索與選用平台](綠建材檢索與選用工具/)使用 TABC 綠建材清單資料，協助建築師及室內設計師進行初步選材。平台可以：

- 依關鍵字、標章分類及材料部位檢索綠建材。
- 查閱核定字號、產品名稱、廠商、標章分類與有效期限。
- 跨健康、高性能、再生及生態綠建材分類比較品項。
- 勾選多項材料並建立具名稱及用途說明的材料組合（Set）。
- 儲存、編輯、匯出及匯入材料 Set，供不同專案重複使用。
- 將 Set 回傳給 Agent，產生建材選用說明書及建議使用部位。

> 平台內個別產品的 CNS 依據、試驗項目及合格項目可能包含依材料類型產生的推論資料，並非逐筆擷取自 TABC 核定文件。正式採購或送審前，應以 TABC 詳細頁面、有效標章證書及廠商檢驗報告核對。

### Agent 斜線指令

| 指令 | 功能 |
|---|---|
| `/GM web` | 啟動本機 GM Web，並開啟 `http://localhost:8888`。這代表使用者已明確同意啟動本機伺服器及瀏覽器，不需再次確認。 |

`/GM web` 是供 Agent 辨識的**對話捷徑**，不是 PowerShell、Command Prompt 或 Bash 指令。若只在問題中提到「綠建材」，Agent 可以直接回答或推薦材料，但在啟動 GM Web 前必須先詢問使用者是否要開啟平台。

平台開啟後，可使用自然語言請 Agent 執行後續工作，例如：「搜尋地板類綠建材」、「幫我建立辦公室地坪 Set」或「請為材料 Set【辦公室地坪】撰寫建材選用說明書」。
