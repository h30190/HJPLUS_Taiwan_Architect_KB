# 綠建材檢索與選用工具

## 使用情境

適用於建築師或室內設計師在案件材料選用階段，需要從財團法人臺灣建築中心（TABC）綠建材標章資料庫中，依部位（牆面、地坪、天花板、塗料等）檢索合格綠建材品項、彙整成一份「材料組合（Set）」，並取得每項建材的標章分類、CNS 試驗依據、合格項目與有效期限，以便撰寫選用說明或送審文件時使用。也適用於 AI 輔助彙整建材選用說明書，或需要向業主／審查單位說明「為何選用此項綠建材」時。

本工具**不涉及任何 BIM 軟體的模型寫入**，純粹是「檢索 → 篩選 → 組成 Set → 產生選用說明書」的資料彙整流程。若需要把材料資料寫入特定 BIM 軟體（如 Revit）的模型元件，屬於另一個獨立工作流程，不在本工具範圍內。

## 平台功能

- 依關鍵字、標章分類及材料部位檢索綠建材。
- 查閱核定字號、產品名稱、廠商、標章分類與有效期限。
- 跨健康、高性能、再生及生態綠建材分類比較品項。
- 勾選多項材料並建立具名稱及用途說明的材料組合（Set）。
- 儲存、編輯、匯出及匯入材料 Set，供不同專案重複使用。
- 將 Set 回傳給 Agent，產生建材選用說明書及建議使用部位。

## Agent 使用方式

### 斜線指令

| 指令 | 功能 |
|---|---|
| `/GM web` | 啟動本機 GM Web，並開啟 `http://localhost:8888`。這代表使用者已明確同意啟動本機伺服器及瀏覽器，不需再次確認。 |

`/GM web` 是供 Agent 辨識的**對話捷徑**，不是 PowerShell、Command Prompt 或 Bash 指令。若使用者只在問題中提到「綠建材」，Agent 可以直接回答或推薦材料，但在啟動 GM Web 前必須先詢問使用者是否要開啟平台。

平台開啟後，可使用自然語言請 Agent 執行後續工作，例如：

- 「搜尋地板類綠建材。」
- 「幫我建立辦公室地坪 Set。」
- 「請為材料 Set【辦公室地坪】撰寫建材選用說明書。」

## 學習目標

- 認識 TABC 綠建材標章的四大分類體系（`GBMTYPE`）：
  - **健康綠建材**：低毒性、低逸散（甲醛與 TVOC）之室內裝修材料
  - **高性能綠建材**：具備隔音、吸音、透水或節能隔熱等物理性能指標之材料與組件
  - **再生綠建材**：利用國內廢棄物回收再利用製造，符合再生材料利用率標準之建材
  - **生態綠建材**：採用天然、無毒、低加工、可再生且低環境衝擊之天然資源材料
- 知道每個標章品項的核定字號（`licno`，格式如 `GBM0104204`）具有有效期限（格式為民國年，如 `115/07/09 ~ 119/07/08`），過期或續證/增證案件（字號後綴 `(續)`/`(增)`/`(變)`）需個別確認。
- 理解本工具的資料真實性分層：`licno`/`title`/`company`/`period`/`category`/`subCategory` 為 TABC 官網列表頁真實資料；`cnsSpec`/`testItems`/`qualifiedItems` 為依關鍵字規則模板產生的**推論值**，不是逐筆從官網詳細頁面（`CaseDataInfo.aspx`）擷取的真實試驗數據——正式送審前務必以 TABC 官方核定文件核對。
- 知道如何用「材料組合（Set）」把多項建材打包成一組，附上專案用途說明，並匯出/匯入專案檔供不同案件重複使用。

## 實務應用

- 依部位檢索：例如檢索「牆體」相關關鍵字時，可同時比對到健康綠建材（牆壁類）、再生綠建材（纖維水泥板、石膏板等板材類）與生態綠建材（木建材、壁紙）等跨標章類別的品項，不應只鎖定單一 `GBMTYPE`。
- 建立 Set 後，可請 AI 顧問依 Set 內容撰寫「建材選用說明書」草稿——內容包含每項建材的標章分類、CNS 試驗依據、合格項目、試驗數據與建議適用部位；正式引用於案件文件前，仍須核對 TABC 官方核定文件或廠商檢驗報告。
- 專案間重複使用：把常用的建材組合另存為專案檔，下個案件開啟即可套用，不必重新檢索。
- 資料更新：TABC 官網會持續新增/更新合格案件，本機快取的主資料庫建議定期重新抓取，避免用到已過期或已下架的品項。

## 常見陷阱

### 陷阱：只看標章名稱，沒確認有效期限
- **嚴重性**：🟡 rework risk
- **何時踩到**：檢索到符合需求的建材，直接引用於文件，未檢查 `period` 欄位的到期日
- **錯誤做法**：假設「查得到就是合格」，不核對有效期限
- **正確做法**：核對 `period` 欄位的結束日期（民國年），過期案件需另尋替代品項或請廠商提供最新續證字號

### 陷阱：把推論出的試驗數據當成官方逐筆核定數據
- **嚴重性**：🔴 rejection risk（若直接寫入正式送審文件）
- **何時踩到**：`cnsSpec`/`testItems`/`qualifiedItems` 欄位是依關鍵字規則模板產生的推論值，容易被誤認為是從 TABC 詳細頁面逐筆核對的真實數據
- **錯誤做法**：直接把說明書裡的試驗數據當成正式送審依據
- **正確做法**：說明書僅供內部彙整與初步溝通參考，正式送審前應以 TABC 官方核定文件（`detail_url`／`CaseDataInfo.aspx`）或廠商提供的檢驗報告為準

### 陷阱：續證/增證字號比對失敗
- **嚴重性**：🟢 minor
- **何時踩到**：Set 內存的是裸字號（如 `GBM0103810`），但主資料庫裡該案件已改列為續證字號（如 `GBM0103810(續)`）
- **錯誤做法**：比對不到就判定「此建材已下架」
- **正確做法**：先用去除 `(續)`/`(增)`/`(變)` 後綴的正規化比對回補，確認是否為同一案件的續證版本，再判斷是否真的下架
