## 使用邊界

- 只使用虛構或去識別化測試資料，不把真實案件封包、簽章、圖檔或個資提交到知識庫。
- 固定筆數、表數與代碼數都是特定版本快照，不是現行官方保證。
- 法規、申辦程序與地方表單要求應另以當時有效的官方來源查證。
