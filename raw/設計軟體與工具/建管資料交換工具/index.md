# 建管資料交換工具 (Permit Data Exchange Tools)

## Skills

* [舊式案件交換格式](舊式案件交換格式/legacy-permit-data-interchange/SKILL.md) - This skill should be used when preserving or producing a legacy CPAMI permit-package data.txt interchange file without treating reverse-engineering evidence as official procedure.
* [書表與資料群組對照](書表與資料群組對照/permit-report-data-mapping/SKILL.md) - This skill should be used when mapping a legacy CPAMI permit report identifier to its actual BMS data groups, computed display fields, or unresolved template dependencies.
* [代碼字典快照治理](代碼字典快照治理/permit-codebook-snapshot-governance/SKILL.md) - This skill should be used when governing a legacy CPAMI permit-codebook snapshot so historical mappings are not represented as current official codes.
* [保真資料儲存模型](保真資料儲存模型/permit-data-fidelity-model/SKILL.md) - This skill should be used when designing storage, import/export, or database projections for legacy CPAMI permit-case data without losing its original string semantics.
