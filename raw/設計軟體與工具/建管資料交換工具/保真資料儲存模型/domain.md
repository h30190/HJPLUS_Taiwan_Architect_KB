# 保真資料儲存模型

本條目說明將既有建管案件格式保存至資料庫或交換 JSON 時，如何保留字串、欄序與擴充資料的原始語意。

它是資料互通的技術設計參考，不取代資安、個資保護、權限管理或正式資料庫治理規範。

## 使用情境

- 規劃既有 `data.txt` 與內部系統間的案件交換。
- 設計能避免前導零、空字串與日期格式失真的保存模型。
- 需要查詢資料庫，但不能讓關聯式整併反向覆蓋原始案件內容。

## 實務應用

以版本化案件封套保存核心資料與延伸資料，將關聯式檢視表視為查詢投影。匯入與匯出邊界才處理 CP950；資料庫與案件 JSON 維持 UTF-8 字串。

## 注意事項

- [Secondary] 此模型來自上游整合計畫，尚非已核定的企業資料庫標準。
- [Unverified] 未經實際部署驗證的 schema 遷移、存取控制與備份策略必須另行審查。
- 案件 payload 可能含個人資料，示範不得使用真實身分、聯絡方式或案件內容。
