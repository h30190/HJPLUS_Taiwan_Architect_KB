
# American ASHRAE Fundamentals（ASHRAE 基礎篇）

## 概述

本技能以 **ASHRAE Handbook—Fundamentals** 為核心，
提供建築空調（HVAC）工程設計、分析、計算及教育用途。

適用於：

- 建築機電設計
- 空調系統設計
- 冷熱負荷分析
- 能源分析
- 室內舒適度分析
- HVAC 教學
