# 無障礙浴室扶手設計檢討

> 無障礙淋浴間與浴室扶手並非單純五金裝設，而是攸關行動不便者人身安全的「防跌與轉位支撐系統」。
> 扶手長度、高度與離牆淨距多為**絕對限制值**，任何因磁磚厚度或管線配置產生的負公差，在使照竣工勘檢時均屬直接卡使照之高風險缺失。

## 使用情境

- 規劃各類建築物無障礙浴室、共用浴室或無障礙客房淋浴空間時
- 繪製建照無障礙專章圖說、標註扶手長度、高度及與水龍頭/牆角之相對距離時
- 室內裝修泥作與輕隔間放樣、在封板前預埋扶手補強結構時
- 使用執照竣工勘驗或無障礙設施專案複查前的自主查核

---

## 核心規範標準：淋浴間扶手與設施要求

依內政部頒布之《建築物無障礙設施設計規範》第六章「浴室」（第 606 節）與第二章「無障礙通路」（第 207 節），淋浴區扶手之法定規格如下：

### 1. 水平與垂直扶手尺寸限制

| 項目 | 規範條號 | 法定標準 | 實務設計與人體工學意涵 |
| :--- | :--- | :--- | :--- |
| **水平扶手高度** | 606.5 | 上緣距完成地板面 **75 ～ 85 cm** | 供輪椅乘坐者及坐在沐浴椅上時支撐手肘與借力。 |
| **水平扶手長度** | 606.5 | **不得小於 120 cm**（$\ge 120\text{ cm}$） | 連續橫向設置於側牆，提供移位至淋浴點的連續抓握。 |
| **垂直扶手上緣高度**| 606.5 | 距完成地板面 **不得大於 150 cm**（$\le 150\text{ cm}$） | 供站立淋浴或輔助起身時之最高抓握點。 |
| **垂直扶手下緣位置**| 606.5 | 距水平扶手上緣 **不得大於 10 cm**（$\le 10\text{ cm}$） | 避免上下段落懸空過大導致使用者換手時落空滑脫。 |
| **垂直扶手與水龍頭距離** | 606.5 | 水平中心距 **不得大於 40 cm**（$\le 40\text{ cm}$） | 單手握牢扶手時，另一手可輕鬆觸及開關水龍頭。 |
| **垂直扶手與牆角距離** | 606.5 | 水平距陰角 **30 cm 以上**（$\ge 30\text{ cm}$） | 預留手背外伸空間，防止抓握時手背碰撞牆角。 |

### 2. 扶手斷面規格與壁面淨距離

| 項目 | 規範條號 | 法定標準 | 說明與常見缺失 |
| :--- | :--- | :--- | :--- |
| **扶手斷面（圓管）** | 207.2.1 | 外直徑 **2.8 ～ 4.0 cm** | 過粗無法完全握緊，過細抓握受力面積不足。 |
| **扶手斷面（其他形狀）** | 207.2.1 | 外緣周長 **9 ～ 13 cm** | 斷面邊緣應為圓弧角，嚴禁銳角。 |
| **與壁面淨間隔** | 207.3.2 | **不得小於 5.0 cm**（$\ge 5.0\text{ cm}$） | 確保手掌能完整穿過握持，避免指節摩擦磁磚夾手。 |
| **上方垂直淨空間** | 207.3.2 | 扶手上緣 **45 cm 內不得有障礙物** | 上方不得裝設肥皂盒、置物架等突出物阻礙握持。 |
| **表面防滑平整** | 207.3.1 | 平整無突起、毛邊、倒鉤 | 建議採不鏽鋼芯包覆防滑抗菌工程塑料（防冰冷）。 |

## 周邊配套設施連動檢討

淋浴區扶手不可孤立檢討，必須與沐浴椅、水龍頭開關、求助鈴及動線整合：

1. **沐浴椅（606.3）**：
   - 應配置具**扶手及背靠**之沐浴椅（座面高度 **40 ～ 45 cm**，防滑）。
   - 水平扶手應沿沐浴椅側向延伸，便於自輪椅移位。
2. **水龍頭及蓮蓬頭（606.4）**：
   - 操作桿與蓮蓬頭高度應設於距地板面 **40 ～ 120 cm** 範圍內，距柱或牆角 **30 cm 以上**。
   - 垂直扶手與水龍頭水平距離不得大於 **40 cm**，應採用單手好撥之槓桿式或恆溫式開關。
3. **高低雙處求助鈴（606.6）**：
   - **高位求助鈴**：按鍵中心距地板面 **90 ～ 120 cm**。
   - **低位求助鈴**：按鍵中心距地板面 **15 ～ 25 cm**（供滑倒在地時拉按觸發）。
4. **迴轉空間與出入口（606.2、604）**：
   - 淋浴區或浴室內應保留直徑 **150 cm 以上** 之淨迴轉空間。
   - 浴室門採用橫向拉門，出入口有效通行淨寬度不得小於 **80 cm**，且無高差門檻。

## 陷阱卡片：無障礙淋浴扶手實務地雷

| 欄位 | 內容 |
| :--- | :--- |
| **陷阱項目** | **施工負公差直接判缺失**（如水平扶手做 118 cm、垂直扶手距水龍頭做 42 cm） |
| **法規依據** | 建築物無障礙設施設計規範 §103.1（施工公差除未註記範圍外，不得大於 3%）與 §606.5（限制型門檻） |
| **失敗後果** | 竣工勘檢時委員拉尺判定不合格 → 必須打掉重裝或更換客製管長 → 卡使用執照 |
| **圖面對策** | 水平扶手圖面標註 **125 cm**，現場放樣預留 2～3 cm 磁磚底層厚度，垂直扶手距水龍頭標註 **35 cm** 預留餘裕 |
| **結構地雷** | 乾式輕隔間牆未預埋鋼板，直接以塑膠壁虎鎖在矽酸鈣板上 → 拉拔受力直接脫落破裂 |
| **結構對策** | 輕隔間封板前於高度 70～160 cm 範圍預埋 **2.0mm 以上熱浸鍍鋅補強鋼板**，螺栓必須牢固攻入鋼板 |
| **嚴重度** | 🔴 高（直接卡使照，且為裝修貼磚完成後之不可逆破壞性修改風險） |

## 設計查核清單

- [ ] 水平扶手上緣高度是否在 75～85 cm 之間？
- [ ] 水平扶手長度是否 $\ge 120\text{ cm}$（無任何負公差）？
- [ ] 垂直扶手上緣高度是否 $\le 150\text{ cm}$？
- [ ] 垂直扶手下緣距水平扶手上緣是否 $\le 10\text{ cm}$？
- [ ] 垂直扶手與水龍頭操作桿之水平距離是否 $\le 40\text{ cm}$？
- [ ] 垂直扶手與牆角陰角距離是否 $\ge 30\text{ cm}$？
- [ ] 扶手管徑外徑是否為 2.8～4.0 cm（圓管）或周長 9～13 cm？
- [ ] 扶手與磁磚完成面之淨間隔是否 $\ge 5.0\text{ cm}$？
- [ ] 扶手上緣垂直上方 45 cm 內是否無置物架阻礙？
- [ ] 乾式輕隔間內是否有預埋 2.0mm 鍍鋅鋼板？
- [ ] 淋浴區是否設置高位（90～120 cm）及低位（15～25 cm）兩處求助鈴？
- [ ] 是否提供座高 40～45 cm 且具扶手背靠之沐浴椅？
- [ ] 淋浴間內部是否有 $\ge 150\text{ cm}$ 輪椅淨迴轉空間？
