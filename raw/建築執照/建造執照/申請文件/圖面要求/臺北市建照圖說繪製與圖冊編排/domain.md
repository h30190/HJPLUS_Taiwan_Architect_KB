# 臺北市建照圖說繪製與圖冊編排

> ⚠️ **僅適用於臺北市**。本技能所記載之圖冊編排架構、44 項申請書圖與會辦檢核、線上無紙化平台檔名前綴編碼（N 系列代碼）、結構外審線上壓章與公會校對副本流程，均為臺北市政府建築管理工程處與臺北市建築師公會之專屬規定。其他縣市之申辦系統、表單代碼及對副本程序均不相同，請勿直接套用於其他縣市。

## 使用情境

- 建築師事務所進行臺北市建造執照（含併辦拆除、變更設計、室內裝修）初次申請或圖冊編排時
- 繪製建照圖面（含 A101~A7 各圖號）與標示各專章（綠化、騎樓、無障礙、避雷、消防、水箱人孔、台電配電場所等）時
- 準備臺北市建照申請 44 項必備書圖、自主檢視表與各局處會辦管制項目時
- 使用臺北市「建築執照線上申請系統（無紙化平台）」進行線上掛號、檔名前綴編碼（N00100~N09900）與上傳 PDF 檔案時
- 配合結構外審線上壓章流程與公會對副本校對作業時

## 學習目標

- 掌握臺北市建造執照圖冊（A101~A7）標準開號與內容規範
- 熟悉臺北市建照申請 44 項書圖檢核重點與特殊管制（捷運沿線、航空噪音、水利排水、文化資產等）會辦條件
- 掌握無紙化系統電子檔前綴編碼（N00100 申請書 ~ N09900 各項證明）規則
- 理解結構外審技師線上壓章機制與公會對副本 11 項必備文件校對流程

## 1. 臺北市建照圖冊標準編排與開號架構

臺北市建造執照圖說原則上採用 A1 規格白紙列印，繪製與開號架構如下表所示：

| 圖號分類 | 圖名 / 內容 | 細部檢討與標示重點 |
|---------|------------|-------------------|
| **A101** | 索引表、基地位置圖、配置圖、面積表、地籍套繪圖 | 包含圖冊目錄索引、都計法規檢討、建蔽率/容積率/免計面積計算列式 |
| **A102** | 現況實測圖 (1:200) | 含鄰地高程、基地內現況植栽、相關公共設施 |
| **A103** | 一層及屋突綠化平面圖 | 檢討《臺北市綠建築自治條例》與《臺北市新建建築物綠化實施規則》 |
| **A105** | 騎樓縱、橫向剖面圖 | 騎樓或無遮簷人行道淨高、淨寬、退縮線與高程對接 |
| **A201** | 筏基平面圖 | 含各水池面積容量檢討，消防水池應附詳剖及面積列式檢討 |
| **A202** | 地下一層平面圖 | 含水箱詳剖及距離尺寸檢討、人孔位置、台電配電場所詳剖、防火百葉、車道淨高 |
| **A203** | 地下二層平面圖 | 停車位編號、車道坡度/轉彎半徑、防空避難室兼停車空間門窗檢討 |
| **A204** | 一層平面圖 | 含排水方向、主要出入口、無障礙通路、避難層出入口 |
| **A205~A210**| 二層至頂樓平面圖 | 各戶平面配置、陽台/梯廳免計面積檢討、採光通風開口 |
| **A211** | 屋突層平面圖 | 含避雷針保護半徑、水箱、機械房檢討、排水方向、消防水塔 |
| **A301~A302**| 東西向及南北向立面圖 | 各層高度、總建築高度、屋突高度、簷高、開挖深度、高度削線/日照削線檢討 |
| **A401** | 橫、縱向剖面圖 | 樓層淨高、挑空/夾層檢討、高度削線檢討 |
| **A5** | 電梯詳圖 | 車廂尺寸、昇降機道 (OH) 及坑深 (PIT) 檢討 |
| **A6** | 門窗圖 | 防火時效、緊急進出口尺寸與標示、採光通風檢討 |
| **A7** | 專章與安全維護圖說 | 含安全維護、通風設備、公寓大廈共用專有圖說、無障礙詳圖 (1:50)、天花平面圖、避雷針詳圖 |

## 2. 臺北市建照申請 44 項書圖檢核與會辦要點

### 2.1 掛號必備 44 項重點檢核

1. **基本申請書類**：建造執照申請書（起造人/承造人/監造人用印）、地號表、建築物概要表、雜項工作物概要表、注意事項附表、基地綠化設施明細表。
2. **切結與同意書**：起造人委託書、高度樓層挑空不違建切結書、基地內無受保護樹木切結書、土地使用權同意書（起造人與土地所有權人不同時）、上傳電子檔與紙本一致切結書。
3. **簽證與專業報告**：建築師簽證表、結構資料檢附表、空氣調節設備資料檢附表、專業技師簽證報告（地基調查、空調、水保、結構技師會員證影本）、綠建築專章檢討報告書（綠化、保水、外殼耗能）。
4. **圖資與謄本**：電腦地籍套繪圖（先申請）、土地登記謄本（3個月內）、地籍圖謄本（3個月內）、土地複丈成果圖、建築線指示(定)圖或免辦建築線公文證明（重劃區）、臺北市都市計畫說明書、公寓大廈規約（含專有共用劃定圖）。

### 2.2 特殊管制與局處會辦條件

| 局處 / 管制類別 | 檢核條件與會辦事項 |
|----------------|------------------|
| **捷運局** | 基地位於捷運沿線地區（7~14天會辦）或聯合開發案件 |
| **停管處 / 交工處** | 停獎案車位超過 150 輛或依都市計畫需進行交通影響評估者 |
| **消防局** | 消防救災空間（8m×20m 救災雲梯車操作空間，距離建物≤11m）或不符消防救災指導原則案件 |
| **文化局** | 古蹟保存區、歷史建築周邊、或涉及《文資法》第 15 條（逾 50 年公有建物）或保護樹木 |
| **水利處** | 水道廢止/改道/加蓋或鄰近山坡地建築排水審查 |
| **特殊管制** | 松山機場航空噪音防制區（附噪音說明書及公告圖）、航空管制高度、基隆河截灣取直大彎南段區、土壤液化潛勢地區 |

## 4. 結構外審壓章與公會對副本 SOP

### 4.1 結構外審線上壓章流程與禁忌
1. 上傳結構圖說與結構計算書至線上平台。
2. 於系統內將「壓章技師」改指定為該案結構技師姓名。
3. 技師登入平台進行線上電子壓章（產生平台 QR Code）。
4. **重要禁忌**：結構外審壓章完成後，若需抽換圖面，**絕對不可將整份檔案刪除重新上傳**，否則技師已壓章之電子副本紀錄將失效重來。

### 4.2 公會校對副本 11 項必帶文件
案件經台北市建築師公會協審室三審通過後，進入對副本階段。帶至對圖現場之 11 項必備文件包括：
1. 建造執照申請書（簽章須與審查正本一致）
2. 變更說明及理由
3. 起造人名冊
4. 設計人名冊
5. 地號表
6. 建築物概要表
7. 雜項工作物概要表
8. 地址門牌清冊
9. 注意事項附表
10. 綠化設施明細表
11. 建照併辦拆照資料表
