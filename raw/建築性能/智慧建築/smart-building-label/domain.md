# 智慧建築標章

## 什麼是智慧建築標章
智慧建築標章是由內政部建築研究所於2004年建立的建築智慧化評估制度，評估建築物透過資通訊系統整合，實現安全、健康、舒適、節能目標的能力。

## 評估指標（6大指標）

| 指標 | 說明 | 鼓勵項目配分 | 權重 |
|---------|------|------|------|
| 基礎設施 | 佈線規劃設計、基礎設施維運、資料設施 | 42分 | 17.5% |
| 維運管理 | 智慧化規劃設計、智慧工地管理、營運維護 | 38分 | 15.8% |
| 安全防災 | 環境安全、人身安全 | 40分 | 16.7% |
| 節能管理 | 設備效率、節能技術、能源管理 | 45分 | 18.7% |
| 健康舒適 | 環境健康、健康管理、便利生活 | 39分 | 16.3% |
| 智慧創新 | 設計手法/系統、智慧營造、智慧建材、標準資料格式、智慧管理雲平台 | 36分 | 15% |
| **合計** | | **240分** | **100%** |

## 基本規定（22項）

依 6 大指標分類，皆為不計分之強制項目：

**基礎設施（3項）**
- 1.1.1 建築物內智慧化所需之資通訊網路垂直主幹佈線採用光纖化架構設計
- 1.2.1 佈線系統應具備標示與可識別機制
- 1.3.1 建築靜態數據庫

**維運管理（4項）**
- 2.1.1 建築智慧化規劃設計
- 2.1.4 使用管理計畫
- 2.3.1 智慧建築監控
- 2.3.2 建築維運管理

**安全防災（11項）**
- 3.1.1.1 火警偵知
- 3.1.1.2 防火區劃之安全梯常閉式防火門狀態偵知
- 3.1.3.1 消防連動門禁及昇降機
- 3.2.1.1 提供即時語音服務
- 3.2.1.3 門禁出入安全管制
- 3.2.1.4 車輛出入安全管制
- 3.2.1.5 影像安全防護與紀錄
- 3.2.1.6 防盜入侵主動告警
- 3.2.2.1 顯示緊急求救位置
- 3.2.3.1 緊急求救連動即時影像
- 3.2.4.1 有害氣體偵知

**節能管理（3項）**
- 4.1.2 照明設備效率
- 4.2.5 水資源資訊揭露
- 4.3.1 能源視覺化監視

**健康舒適（1項）**
- 5.1.1.1 熱環境及二氧化碳濃度狀態偵知

**智慧創新（0項）**
- 無，全部為鼓勵項目

## 鼓勵項目範例
- 基礎設施：無線物聯網網路、5G 專頻專網、資訊安全機制、區塊鏈加密
- 維運管理：智慧工地安全/人員/資材管理、BIM 整合、AI 預測性維護
- 安全防災：漏水/地震偵知、防盜警報連動影像、人流辨識管制
- 節能管理：空調系統智慧化節能、綠能技術（太陽光電）、智慧需量控制、AI 用電管理
- 健康舒適：空氣品質/光環境/水環境偵知顯示、生理監測設施、便利生活服務 APP
- 智慧創新：預鑄工法、智慧建材、智慧管理雲平台、採用標準資料格式（TAICS TS-0054）

## 評估手冊版本
- 智慧建築評估手冊2024年版
- 實施日期：2024年12月1日

## 申請流程
1. 規劃設計階段 → 申請候選智慧建築證書
2. 施工階段 → 依據評估手冊施工
3. 完工取得使用執照 → 向台灣建築中心申請評定
4. 取得評定書 → 向內政部申請認可

## 申請時間
- 候選智慧建築證書：22個工作天內評定
- 智慧建築標章：50個工作天內評定
- 有效期限：5年
