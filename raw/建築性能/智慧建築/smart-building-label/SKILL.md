# Smart Building Label (智慧建築標章)

## Overview
智慧建築標章是由內政部建築研究所於2004年建立的建築智慧化評估制度，評估建築物透過資通訊系統整合，實現安全、健康、舒適、節能目標的能力。

## Applicable Scenarios
- 申請智慧建築標章（已取得使用執照之建築物）
- 申請候選智慧建築證書（取得建造執照之建築物）
- 智慧建築系統規劃設計
- 既有建築智慧化改善

## Key Requirements

### 基本規定（29項）
- 寬頻網路進線
- 住戶配線箱
- 通信設備室
- 緊急廣播系統
- 消防受信總機
- 門禁管制系統
-中央監控系統
- 智慧電表
- 景觀照明控制
- ...等

### 鼓勵項目範例
- 能源管理系統（EMS）
- 雨水回收監控
- 空調變頻控制
- 照明分區控制
- 空氣品質監測
- 智慧交通指引
- 物聯網應用
- AI節能優化

## Assessment Manual
- 智慧建築評估手冊2024年版（2024/12/1實施）

## Application Process

1. 規劃設計階段 → 申請候選智慧建築證書
2. 施工階段 → 依據評估手冊施工
3. 完工取得使用執照 → 申請智慧建築標章
4. 向評定專業機構（台灣建築中心）申請評定
5. 取得評定書 → 向內政部申請認可

## Assessment Timeline
- 候選智慧建築證書：22個工作天內評定
- 智慧建築標章：50個工作天內評定
- 有效期限：5年
