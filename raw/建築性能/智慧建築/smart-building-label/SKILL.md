# Smart Building Label (智慧建築標章)

## Overview
智慧建築標章是由內政部建築研究所於2004年建立的建築智慧化評估制度，評估建築物透過資通訊系統整合，實現安全、健康、舒適、節能目標的能力。

台灣智慧建築協會（TIBA）將「智慧化」的核心判準定義為「**偵知、顯示、連動**」：系統需能感測環境或設備狀態、將資訊即時顯示予使用者或管理平台、並能依偵測結果自動連動其他設備反應，三者缺一不可。這是智慧建築標章貫穿6大指標的共同邏輯，也是與其他建築標章（著重物理效能本身）最大的區別。

## Applicable Scenarios
- 申請智慧建築標章（已取得使用執照之建築物）
- 申請候選智慧建築證書（取得建造執照之建築物）
- 智慧建築系統規劃設計
- 既有建築智慧化改善

## Key Requirements

### 基本規定（22項）

依 6 大指標分類，皆為不計分之強制項目：

**基礎設施（3項）**
- 1.1.1 建築物內智慧化所需之資通訊網路垂直主幹佈線採用光纖化架構設計
- 1.2.1 佈線系統應具備標示與可識別機制
- 1.3.1 建築靜態數據庫

**維運管理（4項）**
- 2.1.1 建築智慧化規劃設計
- 2.1.4 使用管理計畫
- 2.3.1 智慧建築監控
- 2.3.2 建築維運管理

**安全防災（11項）**
- 3.1.1.1 火警偵知
- 3.1.1.2 防火區劃之安全梯常閉式防火門狀態偵知
- 3.1.3.1 消防連動門禁及昇降機
- 3.2.1.1 提供即時語音服務
- 3.2.1.3 門禁出入安全管制
- 3.2.1.4 車輛出入安全管制
- 3.2.1.5 影像安全防護與紀錄
- 3.2.1.6 防盜入侵主動告警
- 3.2.2.1 顯示緊急求救位置
- 3.2.3.1 緊急求救連動即時影像
- 3.2.4.1 有害氣體偵知

**節能管理（3項）**
- 4.1.2 照明設備效率
- 4.2.5 水資源資訊揭露
- 4.3.1 能源視覺化監視

**健康舒適（1項）**
- 5.1.1.1 熱環境及二氧化碳濃度狀態偵知

**智慧創新（0項）**
- 無，全部為鼓勵項目

### 鼓勵項目範例
- 基礎設施：無線物聯網網路、5G 專頻專網、資訊安全機制、區塊鏈加密
- 維運管理：智慧工地安全/人員/資材管理、BIM 整合、AI 預測性維護
- 安全防災：漏水/地震偵知、防盜警報連動影像、人流辨識管制
- 節能管理：空調系統智慧化節能、綠能技術（太陽光電）、智慧需量控制、AI 用電管理
- 健康舒適：空氣品質/光環境/水環境偵知顯示、生理監測設施、便利生活服務 APP
- 智慧創新：預鑄工法、智慧建材、智慧管理雲平台、採用標準資料格式（TAICS TS-0054）

## Application Process

1. 規劃設計階段 → 申請候選智慧建築證書
2. 施工階段 → 依據評估手冊施工
3. 完工取得使用執照 → 申請智慧建築標章
4. 向評定專業機構（台灣建築中心）申請評定
5. 取得評定書 → 向內政部申請認可

## Assessment Timeline
- 候選智慧建築證書：22個工作天內評定
- 智慧建築標章：50個工作天內評定
- 有效期限：5年

## Worked Example (4.2.2 空調系統智慧化節能)

> 出處：智慧建築評估手冊2024年版「案例說明1」

假設某展示廳採中央空調冰水AHU系統，導入以下節能技術（依手冊表2.7「空調節能技術積分表」查得各項積分）：

| 節能技術 | 積分 |
|---|---|
| 冰水主機台數控制及出水溫重置 | 3 |
| 變頻主機 | 6 |
| 二氧化碳濃度外氣量控制系統 | 3 |
| 變風量設計 | 23 |
| 一次冰水變頻系統VPF | 10 |
| 冷卻水泵變頻控制 | 1 |
| 冷卻水塔出水溫度控制 | 5 |
| 執行TAB與Cx（測試調整平衡＋性能確認） | 4+4=8 |
| **節能值總和** | **49** |

依手冊表2.8「節能值對應得分」，節能值達45以上，該評估項目可得**滿分4分**。

**計算邏輯**：同一評估項目下可同時採計多項節能技術，各項積分直接相加；再依累加後的節能值總和，對照分級得分表換算成該評估項目的實際鼓勵分數——不是每項技術各自算分再加總，而是先加總積分、再查表對應得分。

## Related Skills
- [building-energy-rating](../../建築能效/building-energy-rating/)（建築能效標示 BERS）：評估建築物理能效本身（外殼、空調系統效率）之計算與分級，不涉及智慧化控制邏輯。智慧化空調控制（偵知＋連動）雖有助於實際能效表現，但兩張標章評估內容不同，須分別申請、分別送審。
- [green-building-label](../../綠建築標章/green-building-label/)（綠建築標章 EEWH）：評估建築物對環境友善程度（生態、節能、減廢、健康）之綜合指標，與智慧建築標章的評定機構、申請流程相近，但評估內容不同，需個別確認是否兩者皆申請。
- [low-carbon-buildings](../../低碳建築/low-carbon-buildings/)（低碳建築標示 LEBR）：評估建築物營建及使用階段之碳排放量，同屬內政部建研所標章體系，可與智慧建築標章並行申請，但為獨立評定。
